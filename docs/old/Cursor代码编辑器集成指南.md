# Cursor 使用指南


## 一、产品简介
Cursor 是一款 AI 驱动的代码编辑器，通过集成 **Nebula Lab**，可在编写代码时获得强大的 AI 辅助功能，支持智能代码生成、补全、解释及优化。


## 二、快速配置步骤

### 1. 打开设置
点击右上角的齿轮图标 ⚙️，选择 **Models** 选项。


### 2. 配置 API
- **OpenAI API Key**：输入您的 Nebula Lab 密钥（直接使用默认令牌即可）  
- **Override OpenAI Base URL**：勾选并输入 `https://llm.ai-nebula.com/v1`  
- 点击 **Verify** 验证配置是否生效  


### 3. 模型配置说明
- **重要限制**：Cursor 目前不支持 Agent 模式，仅支持 Chat 聊天对话模式（需手动将 AI 生成的代码应用到实际文件中）。  
- **新手建议**：若依赖 Agent 模式进行 Vibe Coding，可选择：  
  - 购买 Cursor 官方会员使用原生服务  
  - 替代方案：VS Code 的 RooCode 或 Cline 插件（均支持 Agent 模式）

## 四、使用模式说明

### Chat 模式工作流程
由于不支持 Agent 模式，推荐流程如下：  
1. **对话生成代码**：  
   - 用 `Ctrl/Cmd + L` 打开聊天窗口  
   - 描述需求，让 AI 生成代码片段  
2. **手动应用代码**：  
   - 从聊天窗口复制代码，粘贴到目标文件  
   - 或使用 “Apply” 按钮（若可用）  
3. **迭代优化**：  
   - 继续对话要求修改，重复应用过程  


### 替代方案对比
| 工具               | Agent 模式 | 优势                          | 劣势                          |
|--------------------|------------|-------------------------------|-------------------------------|
| Cursor             | ❌         | 界面优雅，补全体验好          | 无 Agent 模式                |
| Cline (VS Code)    | ✅         | 完整 Agent 功能，可自动修改文件 | 需要依赖 VS Code             |
| RooCode (VS Code)  | ✅         | Agent 模式，支持多文件编辑    | 较新，功能仍在完善            |
| Continue (VS Code) | ✅         | 开源，可定制性强              | 配置较复杂                    |


## 五、核心功能

### 智能代码补全
- **Tab 补全**：按 Tab 接受 AI 建议  
- **多行补全**：支持函数级别的代码生成  
- **上下文感知**：基于项目结构提供精准建议  


### AI 对话
- `Ctrl/Cmd + K`：打开命令面板  
- `Ctrl/Cmd + L`：打开侧边栏对话  
- **代码解释**：选中代码后可直接询问 AI 含义或优化方向  


### 代码编辑
- **生成代码**：描述需求，AI 自动生成完整代码片段  
- **重构建议**：获取代码结构优化方案  
- **错误修复**：AI 协助定位并修复语法/逻辑错误  


## 六、快捷键
| 快捷键          | 功能                  |
|-----------------|-----------------------|
| `Ctrl/Cmd + K`  | 打开 AI 命令面板      |
| `Ctrl/Cmd + L`  | 打开 AI 对话侧边栏    |
| `Tab`           | 接受代码建议          |
| `Esc`           | 取消当前建议          |


## 七、使用技巧

### 1. 提供清晰的上下文
```javascript
// @context: React组件，用于用户认证
// @requirements: 需要支持OAuth2登录
// @constraints: 兼容NextJS 13+

// AI会基于这些信息生成更准确的代码
```


### 2. 优化提示词
- **不佳示例**：`"修复这个函数"`  
- **优质示例**：`"修复calculateTotal函数中的浮点数精度问题，确保金额计算准确到小数点后两位"`  


### 3. 充分利用 Chat 模式
- 让 AI 生成完整文件内容  
- 要求提供详细修改说明  
- 用于代码审查和重构建议  


## 八、故障排除

### 连接超时
- 检查网络连接是否正常  
- 确认 API 地址为 `https://llm.ai-nebula.com/v1`  
- 验证 API 密钥有效性  


### 模型不响应
- 检查账户余额是否充足  
- 尝试切换其他模型  
- 重启 Cursor 客户端  


### 代码建议质量差
- 提供更多项目上下文（如框架、依赖版本）  
- 使用更具体的提示词  
- 尝试切换性能更优的模型（如 `claude-sonnet-4-20250514`）  


## 九、最佳实践

### 项目级配置
在项目根目录创建 `.cursor-settings.json`，统一配置规则：  
```json
{
  "model": "gpt-4.1",
  "temperature": 0.7,
  "contextFiles": ["README.md", "package.json"],
  "rules": [
    "使用TypeScript严格模式",
    "遵循ESLint规范",
    "添加适当的注释"
  ]
}
```


### 代码规范
在提示中明确规范要求，例如：  
- 使用 TypeScript  
- 遵循 Airbnb 规范  
- 添加 JSDoc 注释  
- 采用函数式风格  


### 安全意识
- 避免在代码中包含敏感信息（如密钥、令牌）  
- 审查 AI 生成的代码，验证逻辑安全性  
- 检查第三方依赖的安全性（如通过 `npm audit`）
