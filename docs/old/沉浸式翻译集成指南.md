# 沉浸式翻译使用指南


## 一、简介
沉浸式翻译是一款优秀的浏览器翻译扩展，支持网页双语对照阅读。通过集成 **Nebula Lab**，可调用强大的 AI 模型，获得更准确、自然的翻译效果，适用于外文阅读、学习、工作等场景。


## 二、快速安装

### 支持的浏览器
- Chrome / Edge / Brave  
- Firefox  
- Safari  


### 安装步骤
1. 访问对应浏览器的扩展商店（如 Chrome 网上应用店、Firefox 附加组件市场）。  
2. 搜索“沉浸式翻译”或“Immersive Translate”。  
3. 点击“安装”并添加到浏览器工具栏。  
4. 或直接访问 [沉浸式翻译官网](https://immersivetranslate.com) 获取安装链接。  


## 三、配置 Nebula Lab
通过 Nebula Lab 调用 AI 模型进行翻译，配置步骤如下：  

1. **打开设置**：点击浏览器工具栏的扩展图标，选择“设置”。  
2. **选择翻译服务**：在左侧菜单中点击“翻译服务”，找到“OpenAI”服务，点击“管理”或“设置”。  
3. **填写配置信息**：  
   - **APIKEY**：输入您的Nebula Lab密钥（从 Nebula Lab控制台获取）。  
   - **自定义 API 接口地址**：`https://llm.ai-nebula.com/v1/chat/completions`（固定地址）。  
   - **自定义模型**：可选填（如 `gpt-3.5-turbo`，默认使用推荐模型）。  


## 四、核心功能

### 1. 网页翻译
#### 自动翻译  
- 访问外文网页时，扩展自动检测语言。  
- 点击工具栏的“翻译”按钮，自动完成整页翻译。  

#### 手动翻译  
- 点击工具栏扩展图标，选择“翻译本页”。  
- 等待几秒后，页面显示翻译结果。  


### 2. 翻译模式
#### 双语对照（推荐）  
- 保留原文格式，译文显示在原文下方。  
- 适合对照学习、核对专业术语。  

#### 仅译文  
- 完全替换原文，适合快速阅读外文内容。  
- 可随时通过快捷键切换回双语模式。  


### 3. 划词翻译  
- 选中需要翻译的文本，点击弹出的“翻译”按钮。  
- 在弹窗中查看译文，支持复制、发音等功能。  


## 五、高级设置

### 1. 自定义提示词  
针对不同内容类型设置翻译风格，示例：  

- **技术文档**  
  ```  
  作为技术文档翻译专家，请：  
  1. 保留所有技术术语的原文  
  2. 在括号中提供中文解释  
  3. 保持代码和命令的原始格式  
  ```  

- **学术论文**  
  ```  
  作为学术翻译专家，请：  
  1. 使用学术规范的表达方式  
  2. 保留引用格式  
  3. 准确翻译专业术语  
  ```  

- **文学作品**  
  ```  
  作为文学翻译专家，请：  
  1. 保持原文的文学美感  
  2. 注意文化背景的转换  
  3. 保留修辞手法的效果  
  ```  


### 2. 翻译规则  
为特定网站设置自动翻译行为：  
1. 进入“翻译规则”设置页面。  
2. 添加网站域名（如 `en.wikipedia.org`）。  
3. 选择行为：  
   - 总是翻译  
   - 从不翻译  
   - 智能判断（根据语言自动决定）  


### 3. 样式定制  
自定义译文显示样式（通过 CSS 代码）：  
```css  
/* 译文字体 */  
.immersive-translate-target {  
    font-family: "Microsoft YaHei", sans-serif;  
    font-size: 14px;  
    color: #333;  
}  

/* 译文背景 */  
.immersive-translate-target-wrapper {  
    background-color: #f5f5f5;  
    padding: 5px;  
    margin: 5px 0;  
    border-radius: 3px;  
}  
```  


## 六、特色功能

### 1. PDF 翻译  
- 支持在线 PDF 文档翻译，保持原格式。  
- 支持双语对照显示，译文可复制。  


### 2. 视频字幕翻译  
支持主流视频平台（YouTube、Netflix、Bilibili 等）：  
1. 开启“视频字幕翻译”功能。  
2. 选择字幕显示方式（如双语叠加、仅译文）。  
3. 调整字幕字体、大小、颜色等样式。  


### 3. 电子书翻译  
- 上传 EPUB 格式电子书。  
- 选择翻译语言和模式（双语/仅译文）。  
- 下载翻译后的双语版本。  


### 4. 输入框翻译  
在网页输入框中实时翻译：  
1. 在输入框输入文本（如邮件、评论）。  
2. 按快捷键触发翻译（默认 `Alt + S`）。  
3. 查看翻译建议并一键替换。  


## 七、快捷键  
常用快捷键（可在设置中自定义）：  

| 功能               | 默认快捷键   |  
|--------------------|--------------|  
| 翻译/显示原文      | `Alt + T`    |  
| 切换翻译模式       | `Alt + M`    |  
| 翻译选中文本       | `Alt + S`    |  
| 打开设置           | `Alt + O`    |  


## 八、模型选择建议  

### 按内容类型选择  
| 内容类型   | 推荐模型          | 原因                     |  
|------------|-------------------|--------------------------|  
| 新闻文章   | `gpt-3.5-turbo`   | 快速、准确，性价比高     |  
| 技术文档   | `gpt-4`           | 术语翻译精准，逻辑清晰   |  
| 学术论文   | `claude-3-opus`   | 长文本理解力强，专业度高 |  
| 文学作品   | `claude-3-sonnet` | 保留文学美感，风格适配   |  
| 日常网页   | `gpt-3.5-turbo`   | 响应快，满足基础需求     |  


### 性能与质量平衡  
根据文本长度和类型自动选择模型（示例逻辑）：  
```javascript  
const selectModel = (textLength, contentType) => {  
  if (textLength < 500) {  
    return 'gpt-3.5-turbo'; // 短文本用快速模型  
  } else if (contentType === 'technical') {  
    return 'gpt-4'; // 技术内容用准确模型  
  } else if (contentType === 'creative') {  
    return 'claude-3-sonnet'; // 创意内容用文艺模型  
  } else {  
    return 'gpt-3.5-turbo'; // 默认用经济模型  
  }  
};  
```  


## 九、性能优化  

### 1. 缓存设置  
- 开启“翻译缓存”功能，减少重复翻译。  
- 设置缓存时长（建议 24 小时），定期清理过期缓存。  


### 2. 批量翻译  
- 调整批量翻译大小（5-10 段落/批），避免单次处理过长文本。  
- 设置合理并发数（2-3 个），平衡速度与稳定性。  


### 3. 触发条件  
- 最小翻译长度：设置为 10 个字符（避免翻译无意义短句）。  
- 忽略元素：过滤导航菜单、广告等无需翻译的内容。  
- 延迟翻译：设置 200ms 延迟，避免频繁触发。  


## 十、常见问题  

### 翻译失败  
- **可能原因**：API 密钥无效、网络连接中断、页面结构特殊。  
- **解决方案**：  
  1. 验证 API 密钥是否正确（从 Nebula Lab 控制台重新获取）。  
  2. 检查网络连接，关闭代理或 VPN 重试。  
  3. 刷新页面，或切换“翻译模式”重试。  
  4. 打开浏览器控制台（F12），查看错误日志排查问题。  


### 翻译速度慢  
- 优化方法：  
  1. 切换更快的模型（如 `gpt-3.5-turbo` 替代 `gpt-4`）。  
  2. 减少单次翻译文本量（拆分长文档）。  
  3. 开启缓存功能，避免重复翻译。  
  4. 检查网络延迟（推荐稳定的网络环境）。  


### 格式错乱  
- 处理方式：  
  1. 尝试切换“双语对照”与“仅译文”模式。  
  2. 在“样式定制”中调整译文布局（如边距、行距）。  
  3. 为该网站添加自定义翻译规则（忽略特定元素）。  
  4. 反馈问题给开发者（通过扩展内“反馈”功能）。  


## 十一、最佳实践  

### 1. 阅读体验优化  
- 选择清晰的字体（如微软雅黑、思源黑体），调整字号至舒适大小。  
- 提高译文与原文的颜色对比度（如原文黑色、译文深灰色）。  
- 设置行间距为 1.5 倍，开启护眼模式（浅灰背景）。  


### 2. 学习辅助  
- 始终使用“双语对照”模式，对照原文学习生词。  
- 用划词翻译查询专业术语，添加到生词本。  
- 导出翻译内容（如 PDF、Markdown），用于复习笔记。  


### 3. 工作效率  
- 为常访问的外文网站设置“总是翻译”规则（如行业资讯站）。  
- 针对专业领域（如编程、医学）自定义提示词，确保术语准确。  
- 熟练使用快捷键（如 `Alt + T` 快速翻译），减少操作步骤。  


### 4. 成本控制  
- 日常浏览用 `gpt-3.5-turbo`，重要文档再用 `gpt-4` 或 Claude 模型。  
- 设置翻译长度限制（如仅翻译超过 50 字的内容），避免浪费。  
- 利用缓存减少重复翻译，通过 Nebula Lab 控制台监控使用量。  


## 十二、高级技巧  

### 1. 自定义翻译脚本  
通过 JavaScript 增强翻译功能（示例）：  
```javascript  
// 自动翻译页面中的文章内容  
if (document.querySelector('.article-content')) {  
    window.immersiveTranslate.translate({  
        selector: '.article-content', // 仅翻译指定区域  
        fromLang: 'auto', // 自动检测源语言  
        toLang: 'zh-CN' // 目标语言为中文  
    });  
}  
```  


### 2. 集成其他工具  
- **Readwise**：保存翻译中的精彩段落，同步到知识库。  
- **Notion**：将双语内容导出为 Notion 笔记，添加批注。  
- **Anki**：用划词翻译的生词制作记忆卡片，辅助语言学习。  


### 3. 开发者模式  
- 开启“调试模式”，查看翻译日志和 API 调用详情。  
- 通过扩展内“反馈”功能提交翻译改进建议或错误案例。  
- 参与开源项目（若扩展开源），贡献翻译语料或代码优化。  


## 十三、故障排除指南  

### 扩展无法加载  
- 检查浏览器版本是否兼容（推荐最新版 Chrome/Edge）。  
- 禁用其他可能冲突的翻译扩展（如 Google 翻译）。  
- 清除浏览器缓存（`Ctrl + Shift + Delete`），重启浏览器。  
- 卸载并重新安装扩展，确保从官方渠道获取。  


### 翻译结果不显示  
- 确认网页内容是否支持翻译（部分动态加载内容可能需要手动触发）。  
- 检查 Nebula Lab 配置是否正确（接口地址、密钥是否有效）。  
- 关闭广告拦截器（可能误拦截翻译请求）。  
- 尝试切换其他翻译服务（如临时使用内置翻译引擎）。  


### 内存占用过高  
- 定期清理翻译缓存（在“高级设置”中操作）。  
- 减少同时打开的翻译页面数量（建议不超过 5 个）。  
- 降低批量翻译的并发数（设置为 1-2 个）。  
- 关闭暂时不用的标签页，释放浏览器内存。
